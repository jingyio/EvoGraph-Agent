# 工作区与 RSI 录制脚本

时长：3–5 分钟。入口：`http://127.0.0.1:5173/#home`、`/#experiments`。

1. 打开工作台，切换财务、客服、技术工单三个岗位，展示 CSV/XLSX/JSON/TXT 上传区、解析后的表字段/缺失值和独立资料列表。说明资料被当作数据，经受限只读工具访问。
2. 在财务岗位加载一个公开来源工作包，查看订单、支付和商品表及原始下载入口。输入工作要求或直接使用已装载请求，确认费用后开始真实运行。
3. 展示当前计划、RSI DAG、当前工作区参数绑定、工具观察、报告与导出清单。强调模型调用以 `M` 显示，确定性图/绑定以 `R` 显示，业务工具以 `T` 显示；没有外部付款、发信或关单动作。
4. 切到一条已保存的客服或工单真实运行，展示报告、证据引用和后续追问入口。指出公开 CFPB 叙述是消费者陈述、GitHub Issues 是公开 issue，而非生产企业数据。
5. 打开实验中心的 V3 预检。展示同任务累计 token、按场景差值、G0 形成和第二轮 Fast 实际使用。说明财务/客服正向、技术工单为负例，严格总节省仅 10.2%。
6. 展示正式 48 项 train 协议的冻结 manifest、串行限制和预估成本；它从新空经验库开始，不能与 V3 拼接。说明没有 Composition/G1/G2 时页面不会绘制虚构进化链。
7. 收尾：报告当前证据证明在线经验积累与 Fast 复用，尚未证明多代结构进化、通用延迟优势、独立 Judge 优势或长期平台期。
