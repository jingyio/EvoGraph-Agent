# RSI 最终串行在线实验协议 V2

日期：2026-09-10。此版本替代 `online-rsi-serial-final-protocol-2026-09-10.md` 的执行版本；V1 的两个任务预检保留为诊断工件，不会计入 V2 正式结果。

## 变化原因

V1 预检中，`finance-installments-06` 的 Graph RSI 已实际读取全部支付记录，但执行模型把任务中“分期数达到 6”错误缩窄为“等于 6”，遗漏一条 10 期订单。报告恢复在相同业务错误签名后按上限终止，没有无限重读。这暴露的是执行阶段任务语义保护不足，而非 evidence 引用问题。

V2 在共享 `TaskRunner` 中增加任务文本派生的包含式比较约束：`至少/达到/不少于/不低于/大于等于 N` 均重申为 `>= N`。该约束只说明原任务已经给出的比较语义，不提供记录 ID、gold、metrics 或选中结果；无法由当前数据可靠决定的其它条件仍交给模型。它同时作用于 `Plan + ReAct` 与 `Graph RSI`，因此 V1 和此前历史 Baseline 都不能与 V2 混接成严格对照。

## 不变部分

- 36 个固定 train 任务、六轮到达顺序、相同模型/提示/预算/工具和确定性评分。
- 单 Agent 串行：`run_limit=1`、`model_limit=1`、`read_limit=1`。
- Baseline 无跨任务学习；RSI 从 V2 专用空经验库开始，任务完成后才更新并对下一个任务开放经验。
- 报告证据仅在所有本任务记录已真实观察时规范化；缺观察不注入引用。Judge 始终在 Agent 全部完成后双顺序运行，费用单列。
- 预检包含两个历史长尾任务及一个单独的 10/30/60 条串行规模工件；成功后前两轮 12 条可直接计入正式 36 条流，期间不得变更结果相关代码或配置。
