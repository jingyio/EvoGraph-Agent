# 工作区与 RSI 录制脚本

时长：3–5 分钟。入口：`http://127.0.0.1:5173/#home`、`/#experiments`。

1. 打开 `/#home`，切换财务、客服、技术工单能力。展示 CSV/XLSX/JSON/TXT 上传区、已解析资料、字段/缺失预览和来源下载；资料仅经受限只读工具访问。
2. 在财务能力加载公开来源工作包或上传资料，输入业务要求。缺资料时展示确定性澄清；资料齐备后确认费用并启动真实 Agent。
3. 在同一次 run 中展示 DAG、当前参数绑定、模型 `M`、结构化运行时 `R`、工具 `T`、报告、CSV 导出与 HTML 下载。每一项都从同一 run ID 读取；没有外部付款、发信或关单。
4. 在同一工作区对该报告追问，强调父报告只有用户可见摘要；追问仍以本次工具读取和 evidenceIds 交付。切换到客服、技术工单各完成一次相同链路，说明 CFPB 是公开消费者陈述、GitHub Issues 是公开 issue。
5. 打开 `/#experiments`，选 V17 正式 train 工件。展示冻结 48-task manifest、串行 1/1/1、两臂 48/48 私有结构化通过、累计 token 2,244,017→1,243,546、模型请求 258→149，以及三场景分解。
6. 用 family 选择器展示一个 G0 形成后在后续实例被 Fast 实际复用的链，并展开完整恢复账本：报告尝试、失败尝试、资料范围补齐、工具拒绝/错误和 usage 完整性均包括全部尝试。
7. 收尾：本轮证明固定公开工作包上的在线经验积累与 Fast 复用；没有 Composition、G1/G2、多代结构进化、独立 Judge 或生产写入结论，页面不会把它们画成已发生的能力。
