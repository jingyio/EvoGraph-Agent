# 0–10 评分与 0–1 reward 验证

当前协议三项为 factuality、coverage、readability，整数 0–10；后端按 0.5/0.3/0.2 加权并除以 10。每对交换 A/B 顺序评价两次，按真实策略身份还原后取平均，保留两次分数和 reward 范围。reward 是质量分，不是成功概率，不覆盖确定性事实校验。

裁判使用当前默认 qwen/qwen3.5-27b，与执行模型相同，不构成独立模型质量验证。性能评测结束后才运行裁判，费用与 Agent 成本分开。
