# 轨迹 RSI V1 预检协议

2026-09-14，新建独立 runtime 与 `trajectory-review-v1` 资产，不重写 V17。
用户本次明确授权小规模预检，健康后扩大严格串行对照。当前模型为
qwen/qwen3.5-27b，执行/规划同模型、thinking=false。每个 Agent 上限沿用
24 模型请求、80 工具、180 秒，模型匹配计入同一上限；不运行 Judge。

## 冻结安排

先财务同组3个正常 train 实例，再客服3个、技术工单3个，两臂共18次。
每对顺序交替，两臂分别保持相同的实例到达顺序；run=model=read=1。
首个失败/未知usage/维护错误 pair 完成后停止扩大，保留其全部尝试，禁止胜负重试。
完整后续对照采用三组×8实例=24条train，以控制本阶段预算；这是对交接中建议
三场景×两组×8实例的有界缩小，第二代表工作流组不在本轮验收范围，不能称48条完成。
另各场景保留1 validation、1 test，不在本轮付费运行，也不用于学习。
相邻四任务窗口只作描述性检查；任务条件与规模分别记录，不声称修订导致收益。

来源为本地已缓存 Olist、CFPB、Zammad GitHub Issues；按原始来源split和固定哈希
选择不同记录，每财务实例12订单、其他场景10主记录。不修改公开记录，不注入工具
故障。CFPB消费者文字只提供1200字摘录并显式标注截断；不是完整客服对话。
附加交付要求在第3/4/7/8个请求明示，实例2变更当前数值；不延后已可验证节点编译。
完整附件、问题、私有评分与来源manifest位于 `artifacts/trajectory-review-v1`。

## 已实现与待检边界

- 初始图来自通过评分的实际工具收据，保留sourceRun/traceIndex/digest；未执行Plan
  不入经验。嵌套table和task槽支持逐字参数来源，字段/schema/type先验检查。
- 由实际操作及源请求形成适用描述，一次有界模型匹配判断当前语义/单位/运算与覆盖；
  BM25/字元召回不直接接受。禁止family/template/workpackId/privateValidation进入匹配。
- 确定性读取和compute由图调度。分页以本次mayHaveMore终止。无可靠参数的节点、
  正文和本地产物仍为明确模型边界；当前不是任意嵌套output绑定的完整工作流编译器。
- G结构与M适用描述有独立字段和diff；有真实成功后继轨迹才保存结构变化。
  当前实现能随结构覆盖变化修订描述，独立M-only修订及后续行为链仍需证据与完善。
- 上传工作区仍不学习，未审核经验不能自动载入。旧模板读取经验不用于本轮。
- 多原因groups、当前证据与运行内artifact幂等对两臂共享。金额缺失值为null，不当零
  完成对账；按完整关联资料分别检查差额、分期，保留重叠与空组。原始分/BRL显示分开。

## 账本与判定

每个尝试保存模型/provider attempts、usageComplete、match/plan/execute阶段token、
工具拒绝/错误/报告恢复、本地compile/binding/maintenance/persistence和端到端时长。
局部嵌套耗时不重复求和；净收益包含冷启动与匹配。首要验收分别为实际G/M修订及后续
使用、约30%净token目标、同run业务成果/轨迹/曲线可录制；任何未发生项标未达标。
私有真值只判断报告通过/失败，不给模型、匹配或编译提供预期数字和ID。
