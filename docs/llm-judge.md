# LLM-as-Judge 与 Plan 消融

## 判定范围

原确定性评分继续检查金额、计数、筛选结果与证据覆盖。LLM 裁判负责事实表述、任务覆盖与可读性，不把两类评分合并成一个看似精确的总分，也不改写原始任务成功标记。

每对报告调用裁判两次。第一次随机分配 A/B，第二次交换顺序；两次调用彼此独立，不把前一次意见放进下一次上下文。裁判只看到任务、共同来源记录和两份提交报告，不能看到 Agent 名称、模型名、token、耗时、执行图或确定性评分。报告自己的自称不改写，元数据匿名不能保证内容完全不可识别。

共同证据来自该任务范围内冻结历史记录，读取证据的接口只在评测模块中使用；不载入 gold，不向原 Agent 注入新数据。数据集摘要变化或证据超过 200000 字符时拒绝执行，不静默截断。提示明确把报告和证据视作不可信数据，仍不能保证完全免疫提示注入。

Rubric：factuality（事实一致性）、coverage（任务覆盖）、readability（可读性）分别为 0–10 整数。9–10 充分满足，7–8 轻微问题，4–6 有实质遗漏，1–3 严重问题，0 缺失/无法使用。A/B 各给出一条主要问题说明并用 evidenceRef 引用实际证据；无问题时明确说明。findings 使用固定 A/B 对象，不使用容易被当前模型字符串化的数组。

后端固定计算，不让模型自由生成 reward：

```text
reward = (0.5 × factuality + 0.3 × coverage + 0.2 × readability) / 10
```

例如 8、9、10 分得到 0.87。每次顺序都保留各维度分数与 reward；最终对两个顺序取平均，并保留 reward 最小/最大值。各维度平均分允许小数，最终 reward 范围为 [0,1]，这是归一化质量分，不是成功概率。胜负根据每个顺序的 reward 计算，两次方向不一致标记 inconclusive；即使平均 reward 有差异也不掩盖顺序分歧。两次都为平局不等于统计等价性证明。

reward 仅表示裁判对报告质量的评分，不混入 token 或 latency，也不覆盖原确定性校验。格式或引用校验失败不产生有效 reward，不能把失败默认计为零分。旧 0–4 实验记录保留为旧版，不与当前 reward 混合。

只做一次双顺序裁判，不因偏好结果重试；每个顺序最多一次仅针对 schema 格式的修正，最多四次请求，原始格式错误与费用保留。错误证据引用或顺序分歧不触发修正。相同输入、裁判模型和 rubric 的请求返回已有记录。格式错误、服务错误、取消和顺序分歧都保留。

## 配置与开销

可选 `.env` 字段：`JUDGE_MODEL`、`JUDGE_BASE_URL`、`JUDGE_API_KEY`；缺省继承执行模型配置。HTTP 仍全部经过 `backend/model_client.py`，关闭 thinking。不填写独立模型时前端明确显示同模型裁判，不能据此声称有独立模型验证。更严格的最终实验应使用独立的更强裁判并抽样人工校准。

裁判模块不执行 Agent、不生成图、不学习、不改写已有执行指标。每次请求的输入/输出 token 和裁判耗时分别保存，失败用量缺失标记为不完整。裁判与任务性能实验不同时执行，以免裁判流量影响 Agent 延迟。

```text
GET  /api/evaluations/<id>/judgements
POST /api/evaluations/<id>/judgements
{"pairIndex":0}
```

前端 `#evaluation` 每对报告下有“LLM 裁判评价这对报告”，显示双顺序分数、理由、证据、分歧和独立成本。持久化位于 `artifacts/llm-judgements/<id>.json`；新记录的共同证据与报告输入另存于 `artifacts/llm-judgements/inputs/<id>.json`，不提交 Git。

## Plan 已可复用

Graph RSI 的已保存版本同时包含 Plan 和读取图。命中时复用两者，Plan 请求为零。冷启动才调用规划模型；原评测只有三个类型有历史图，所以 27 个任务仍冷启动。

新增成对评测参数 `baseline: "plan_react"`，默认仍为 `strong_react`。两种基线和 RSI 共用通用观察复用、防重复与批量提示。Plan + ReAct 调用规划器后，仍由模型根据计划和观察发出工具调用；RSI 用确定性 DAG 执行稳定读取结构。模型规划可能有差异，因此这个对照用于比较架构，不等于固定同一份 Plan 的纯执行器消融。

如果基线也复用 Plan，可以消除其规划成本；如果进一步直接执行编译图，则已经具备同类结构执行机制，不能承诺 RSI 仍然有同样幅度的收益。历史学习、负 Motif 和递归改进需要各自的对照证据。
