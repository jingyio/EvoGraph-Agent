# Trajectory Review V3：运行前任务与工具审阅草案

日期：2026-09-14。此文件是 `trajectory-review-v3` 的**任务内容审核稿**，不是已冻结资产、
不是运行结果，也不触发模型调用。现有 `trajectory-review-v2`、V17、V4 和保存的运行工件保持不变。

## 当前结论

不要批准 `trajectory-review-v2` 进入正式运行。它的 48 个 train 任务本质是六个完整问题
各八次的记录/阈值变体，无法检验异构任务中的局部学习、组合、M 修订及修订后使用。

V3 将冻结为 48 个 train（每岗位16个）、6 个 validation、6 个 test。训练任务的顺序在
运行前固定；`family`、`motif`、难度特征和私有答案只用于离线评分，绝不传给 Agent、
召回、匹配或编译器。

## 任务公共形式

模型只接收当前业务请求、当前附件解析出的表/字段、要求交付的结构化报告契约，以及20个
共享工作区工具。模型不会看到任务标签、题号、黄金答案、历史业务ID或实验分组。

```json
{
  "scenario": "finance | support | tickets",
  "split": "train | validation | test",
  "request": "自然语言业务问题：范围、口径、阈值、缺失处理、证据和禁止动作",
  "schemaContract": {"tables": [{"id": "当前表角色", "fields": ["当前字段"]}]},
  "deliveryContract": {
    "requiredMetricKeys": ["当前题面明确声明的整数指标"],
    "requiredGroupNames": ["当前题面的独立原因组"],
    "evidenceScope": "仅限本次附件的实际观察"
  }
}
```

每题的结构化报告均要求 `metrics`、每个原因的 `groups`、业务 `selectedIds`、当前行
`evidenceIds` 和简报正文。`groups` 可以重叠；空组必须如实提交 `count: 0`。

## 共享工具形式

两臂都使用同一工作区工具集：14个只读、3个确定性计算、3个本地产物。没有网络搜索、
外部消息、付款、改账、指派、关单或代码执行工具。

| 类别 | 工具 | 核心输入 | 结果边界 |
|---|---|---|---|
| 读取 | list_sources / get_schema / profile_table | 当前工作区或表 | 资料、字段、类型、缺失 |
| 读取 | preview_rows / get_row / filter_rows / sort_rows | 当前表、字段、声明条件 | 当前行和稳定证据引用 |
| 读取 | join_rows / compare_tables / search_text / find_evidence | 显式表键或文本查询 | 当前关联、变化、文本证据 |
| 读取 | get_policy_excerpt / get_task_context / list_saved_reports | 当前附件或本工作区 | 资料原文、边界、已有摘要 |
| 计算 | aggregate_rows | 当前表、聚合、可选分组 | 总量或逐组统计 |
| 计算 | ordered_partition | 当前表、稳定排序、措施 | 确定性前后段比较 |
| 计算 | reconcile_keyed_sums | 当前表、显式键、聚合/比较 | 一对多汇总、缺失、命中与证据 |
| 本地产物 | save_draft / export_csv / publish_report | 当前模型正文或当前行 | 本地草稿、CSV、校验报告 |

RSI额外控制面只有 `submit_plan`、`bind_trajectory`、`request_tools`：不读取业务资料、不写入
外部系统。新的 `bind_trajectory` 将只在已存在候选片段时作一次有界选择，返回当前槽绑定、
覆盖范围和拒绝理由；它不能提供旧业务值或私有答案。

## 审核门槛

批准冻结前，需确认：

1. 这48种业务义务和12对预检覆盖集符合演示所需的工作范围；
2. 缺失、空组、单位、跨期对比等口径没有被隐藏为系统默认规则；
3. 本地草稿、CSV和报告是允许的产物，而任何外部业务写入均被禁止；
4. V3应在完成数据流引用、片段组合和M反馈协议测试后，再从空经验库启动12对预检。

审核通过后才会把这份矩阵落实为冻结的公开记录清单、题面哈希、私有评分与实验manifest；
在此之前不启动任何模型调用。
