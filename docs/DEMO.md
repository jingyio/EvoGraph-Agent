# 演示路线

[观看 2 分 19 秒录屏](../media/rsi-agent-demo.mp4)

建议三分钟内按以下顺序展示：

1. 打开数字员工工作台，展示自然语言业务请求、附件与同题三臂执行。
2. 对比传统 Agent、图执行但不学习、图执行且在线 RSI；强调学习贡献应看后两者。
3. 播放 FX01 到 FX12 的保存回放：FX01 创建经验，后续任务首次复用，再展示 G/M 修订与新版本实际使用。
4. 打开累计成本与请求可靠性，说明所有失败和恢复开销均在曲线中。
5. 回到候选状态与限制：当前结果可展示固定财务范围内的真实观察，尚不构成跨领域正式性能声明。

页面、完整回放和可下载报告位于 [`develop`](https://github.com/jingyio/EvoGraph-Agent/tree/develop) 分支的前端工程中。此分支仅保留录屏和审阅材料。
