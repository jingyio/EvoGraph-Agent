# 三分钟录制脚本

入口：`http://127.0.0.1:5173/#analysis`。只使用发布清单明确指定的一套六任务工件，所有保存轨迹称为回放。

0:00–0:30：打开“数字员工”，说明用户输入的是简洁业务请求和当前附件。财务以 Olist 公开历史记录为材料，不是生产企业 API 写入。Agent 自主选择通用工具，机器评分契约不替用户分解步骤。

0:30–0:55：进入数据分析，展示当前实验 ID、runtime、资产版本与状态。说明 A 为“图执行 · 不学习”，B 为“图执行 · 在线RSI”，共享模型、提示、工具、编译、恢复和预算。仅 B 能读取此前成功任务学到的经验。排除旧 Plan+ReAct 和历史 V17/V4 指标。

0:55–1:20：点击第一个任务，展示当前订单财务报告和清单。说明这是冷启动创建 G0/M0，其成本计入总量，不是学习收益。打开真实轨迹，展示实际映射、聚合、关联、比较与报告；工具独立调用允许批量。

1:20–1:50：点击相近后续任务，展示实际执行的历史版本、当前参数和节点。强调计算收据属于当前 run，所有金额与业务 ID 重算；复杂单位转换可以交回模型。对照真实模型请求和 token，不能按节点数换算请求。

1:50–2:20：展开正常任务反馈产生的 G/M diff，核对来源 run 和后续实际使用任务。只有实质修改及后续执行才称为修订链；若本次未获得，直接说明“证明经验复用，尚未证明反馈进化”。覆盖新状态义务称为覆盖扩展；不能将 G0、support 增长或版本数字变化称为进化。

2:20–2:45：展示单次和累计 token、模型请求和串行 latency。首任务、匹配、失败、恢复、学习与保存均计入。解释单次波动和净值；模型服务时延不是纯计算耗时，曲线不要求单调。准确率仅代表本次结构化事实/证据评分，报告正文仍需人工审查。

2:45–3:00：下载同 run 的业务报告，查看可靠性和限制。结论限定于这条预先冻结的六任务链；不能宣称长期零错误或普遍收益。失败预检与历史实验可从开发/历史审计，不加入当前指标。
