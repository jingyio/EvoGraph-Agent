# 项目概览

EvoGraph Agent 面向重复出现的运营任务。传统 Agent 每次都要重新理解问题、选择工具、填充参数和组织报告。Graph RSI 将一次成功任务的真实执行轨迹编译为图，并在相似任务到来时复用已经验证的决策结构。

运行分为四步：

1. 当前任务仍由模型理解，系统只从当前附件获得记录、字段、阈值和证据。
2. 匹配器判断既有图或子图是否适用；不能验证时回退给模型。
3. 图执行器运行已验证节点，未覆盖义务继续交给模型完成。
4. 正常成功任务可以产生有来源的 `G` 结构或 `M` 匹配描述修订，后续任务必须实际执行该版本才算验证。

当前候选使用财务复核：订单是复核主体，同一订单可对应多笔支付与多条商品明细，金额原始字段以分保存，报告按 BRL 展示。系统不复制旧订单 ID、金额或报告正文。

项目使用公开历史数据构造冻结任务：Olist 财务记录、CFPB 投诉记录和 Zammad GitHub Issues。它们不是生产企业数据库；公开数据、项目初始化的演示记录和真实平台数据在开发分支中分开标注。

完整架构、任务库、协议和源代码在 [`develop`](https://github.com/jingyio/EvoGraph-Agent/tree/develop) 分支。`main` 只保留交付所需的事实说明与演示材料。
