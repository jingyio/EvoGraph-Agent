# Python/FastAPI 迁移与验证

日期：2026-09-09。React 前端保留，Agent 后端迁移到 Python；TS 原型已提交在 `e63b138`，不再同时维护两套后端。

## 迁移内容

- FastAPI 保持原有 `/api/config`、`/api/runs`、`/api/tools`、`/api/graphs`、导出与平台检查接口。
- `backend/model_client.py` 是唯一 LLM HTTP 边界。ReAct 和经验规划器注入同一个接口；固定 `enable_thinking=false`，OpenRouter 同时关闭 reasoning，并允许模型在一次响应中返回多个独立工具调用。
- AutoTool 使用同一平台 OpenAPI 子集生成 7 个读取工具。业务沙箱使用冻结的 JSON schema 和快照，避免语言迁移时悄悄改变数据。
- NetworkX 检查任务图拓扑和循环；支持参数来源、集合遍历、分页、候选检索、节点选择、依赖补齐和 ReAct 回退。
- 新图保存在 `artifacts/graphs-python/`，包含 Python 运行时指纹。旧图不会直接执行，可从旧真实轨迹重新编译并影子验证。
- JSON/Markdown 历史记录继续可读；旧实验产物不改写、不混入新指标。

## 校验增强

模型结束后进行独立的确定性任务状态校验。有缺项时最多回传模型修正两轮，使用相同模型接口并计入总请求预算。达到预算、取消或超时后保存部分结果与校验信息，失败任务不自动保存新经验。

预设任务自动使用完整岗位校验；自定义任务默认仅检查状态不变量，界面可显式选择完整流程目标。未选择完整目标时不能把通过状态约束解释为完成了全部任务。报告文字、单位和因果解释尚无完整自动评分。

## 运行入口

```bash
npm start
# 等价于：
.venv/bin/python -m backend serve
```

服务仍监听 <http://127.0.0.1:4317>，接口文档在 `/docs`。`npm run dev` 热重载 Python 文件，React 修改后执行 `npm run build`。
