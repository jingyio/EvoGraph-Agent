# RSI 最终串行在线实验协议 V3

日期：2026-09-10。此版本替代 V2 的执行版本；此前工件均保留，但不得与 V3 结果拼接。

## V3 修订：区分分页遗漏与引用格式

V2 的 60 条串行规模预检显示 Baseline 在列表第一页（50 条）后提交报告。由于 runtime 把 `evidence_coverage` 一律分类成引用格式，它只开放 `publish_report`，阻断了读取第二页，最终有界失败。这不是缺少引用前缀，而是未完整观察任务范围。

V3 的共享恢复分类如下：

- 若本任务全部必需记录已经在当前 `ToolContext.evidence` 中，`evidence_coverage` 才是引用格式问题；runtime 可规范化完整观察集合，且不重读业务数据。
- 若仍有本任务记录没有真实观察，分类为 `missing_evidence`；runtime 不注入 refs、不提供 gold 或结果，只提示模型根据 `mayHaveMore` 继续分页或读取本范围尚未观察的必要记录，然后允许一次有界再提交。
- 相同失败签名或第二次失败仍会终止，重复的成功读取在恢复期间被阻断。

这同时作用于 Baseline 和 RSI。V3 的长尾 V2 预检不命中这一新增分支（首次报告前已完整观察），因此它保留为兼容的长尾健康证据；10/30/60 规模点需要以新的 V3 工件重跑。

## 其余冻结协议

其余条件继承 V2：36 个固定 train 任务，六轮固定到达顺序；`run_limit=model_limit=read_limit=1`；相同模型、提示、工具、预算与事实评分；Baseline 无跨任务学习，RSI 从独立空经验库开始；Agent 全部完成后才运行双顺序 Judge，Judge token 单列。并发矩阵不运行，也不进入主结论。
