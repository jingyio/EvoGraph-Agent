# Graph RSI v0.2

实现借鉴本项目对 AutoTool、G-Agent 和 MotifAgent 的职责划分，未声称复现某篇同名论文或官方实现。当前范围是**从真实执行轨迹学习读取图，并在后续任务中重新绑定数据、选择图节点和执行**。

## 三层如何协作

| 层 | 已实现内容 | 当前边界 |
|---|---|---|
| AutoTool | 从本地 OpenAPI 契约生成 HTTP GET 包装、类型校验、路径编码、响应提取与来源指纹 | ERPNext 3 个详情工具和 Zammad 4 个读取工具；规格由已联调 API 整理，不是平台自动发现或任意代码生成 |
| G-Agent 思路 | 检索历史任务图；相同任务直接命中；相似任务由模型选择候选图与必要节点，补齐数据依赖；成功适配后校验并保存新版本 | 检索是字符二元组相似度，模型只在候选集中选择节点；当前使用同一个已配置模型，没有额外大小模型策略 |
| 结构执行 | 从成功读取轨迹推断参数来源、遍历和分页，按 DAG 依赖执行；条件不满足时返回 ReAct | 仅编译第一次写入或报告生成之前的读取前缀，不复用旧报告、旧回复或业务写入 |

AutoTool 自动生成的工具与手写列表工具共同进入同一个 registry。普通 ReAct 与 Graph RSI 都能使用完全相同的工具；工具目录会标记 AutoTool 来源和契约指纹。新工具获取能力已通过额外测试规格验证，但未实现无限制的运行时插件安装。

## 使用工作台

1. 打开 <http://127.0.0.1:4317>，从“最近运行”选择一次正常结束的真实模型任务。
2. 打开“任务图经验库”，点击“从当前运行学习”。系统编译读取轨迹，并重新执行读取进行影子验证；通过后保存图版本。
3. 点击“使用这份经验”，进入 Graph RSI 模式。内置沙箱可选择“新周次”或“例外”快照，检查新 ID、新金额、新记录和人员不可用等变化。
4. 执行轨迹记录图节点、实际工具请求、模型续跑和回退；点击图节点查看参数绑定及来源事件。

也可以直接选择 Graph RSI 运行：没有适用经验时用普通 ReAct 完成任务，随后自动编译、校验并保存读取图。没有成功完成的运行不会被自动学习。影子验证失败则保留运行结果和失败原因，不发布图。

离线固定流程不允许作为学习来源，也不允许切换为 Graph RSI；真实模型未配置或不可用时不会降级为伪造的 LLM 结果。

## 图结构与守卫

每个图包含来源运行、任务文本、版本、工具契约指纹、实例指纹、节点和依赖；不保存历史观察结果。

参数绑定分为：

- `literal`：schema 枚举或页码/页大小等控制参数。
- `item`：从本次上游集合或单条记录读取字段，例如 `list_payments[].id → preview_payment_match.paymentId`。
- `result`：执行器支持单值结果路径引用；当前编译器主要生成 item 绑定。

编译器遇到无法证明来源的 ID、日期、金额或自由文本时停止编译，把剩余工作留给模型。它只保留成功的读取观察，去除同构的重复读取；不能从一次样本证明分支条件完全稳定。把单条读取提升为集合遍历可能增加工具调用，因此必须单独比较工具数和 token。

相同任务命中要求场景、数据源、实例和工具契约一致。任务匹配只抽象明确的“以 ISO 时间为本次巡检时刻”字段，不能忽略任意截止时间或金额约束。相似任务由规划器检查是否适用；规划器不能改变工具实现、任意生成图节点或授权写入。

执行器拒绝写节点、循环依赖、缺失依赖和不安全路径。集合类型变化、接口失败等触发 ReAct 回退，并把本次已读取的观察保留给模型。分页最多 20 页，集合最多 1000 条，所有真实工具调用仍受总工具上限约束。取消和总超时作用于图、规划和模型续跑。

## 计量与验证

- 运行 `metrics.modelRequests` 包含经验规划器和任务执行模型的所有请求，包括失败请求；token 累加供应商实际 usage。
- `run.graph.plannerRequests` 单列经验规划次数。精确命中不需要额外规划调用；相似任务通常需要 1 次，可能抵消部分节省。
- `run.graph.toolCalls` 是直接由图执行的工具调用数，已包含在运行总工具数中。
- 编译学习没有额外 LLM 请求，但有影子读取成本；图的 `validation` 记录 compileMs、durationMs 和 toolCalls。
- 冷启动的学习成本单列在 `run.graph.learning`，执行耗时不包含学习后的校验耗时。手动从旧运行学习的成本记录在图元数据中。
- 原始源任务的模型成本保留在 sourceModelRequests/sourceInputTokens/sourceOutputTokens，不能忽略先收集轨迹的成本。
- 影子验证仅证明读取调用、参数绑定和无沙箱状态变更；不证明整个任务或报告语义正确。

`npm test` 包含新 ID/金额/记录、分页扩展、来源错误、接口形状变化、写入阻断、规划器非法选择、规划错误回退、用量统计与版本持久化测试。`npm run verify:platforms` 验证 AutoTool 生成的真实平台工具。

## API

| 方法与路径 | 功能 |
|---|---|
| `GET /api/graphs?scenario=finance&source=sandbox` | 查看当前经验库 |
| `POST /api/runs/{id}/learn`，JSON `{}` | 从已完成真实运行编译并验证图 |
| `GET /api/graphs/{id}/export` | 导出图 JSON |
| `GET /api/snapshot?variant=changed` | 查看变体业务数据 |
| `POST /api/runs` | 使用新增 strategy 和 snapshot 字段运行 |

新增请求字段：`strategy: "react" | "graph"`，`snapshot: "base" | "changed" | "exception"`。旧请求默认 react/base；外部平台只能使用 base（真实实例数据）。任务图和运行产物保存在被 Git 忽略的 `artifacts/` 中，图文件权限为 0600。
