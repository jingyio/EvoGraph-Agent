# 轨迹驱动的负 motif

本实现聚焦 graph-based 经验：正 motif 是可复用的执行子图，负 motif 是带适用条件的失败与修复关系图。GEPA/Hermes 只作设计参考，没有引入依赖或替换 Agent Runtime。

## 实现范围

`backend/negative_motif.py` 支持第一种固定编译语法：财务重复流水登记时，将 `list_payments[].bankRef` 错绑到 `create_finance_case.entityId`，随后改绑同组回款 `id` 成功。

数据观察 → 错误字段绑定 → 工具失败 → 修正字段绑定 → 局部成功。

图记录每个节点的来源事件序号，依赖边表达数据来源与时间先后，不把一次对照宣称为任意任务的因果定律。NetworkX 验证 DAG；运行时使用与规则版本对应的固定匹配器。编译语法和适用谓词由开发者实现，具体错误实例、修复证据和经验是否可启用来自轨迹。它不是通用的自主规则发现或任意代码修复。

失败和成功调用的结构化参数必须仅在 entityId 上有差异（文案不作为证据）。编译器先重放之前成功的沙箱操作恢复错误发生前的状态，再在该状态验证错误参数确实失败、失败不修改状态、修复参数成功。所有重放均在独立副本，不触及原运行或外部平台；影子工具调用单列，额外 LLM 为零。

全任务失败、达到预算并不禁止提取局部修复证据。负 motif 存于独立的 `artifacts/negative-motifs/`，不将失败运行晋升为成功工作流。没有修复、网络失败、能力缺失、其他类型错误保留待分析，不能自动变成禁用工具规则。状态校验漏项和成本退步尚未编译成负 motif。

## 使用与归因

先在运行历史加载一条真实轨迹，进入“负 Motif · 失败反思”，点击“分析当前轨迹”。也可调用 `POST /api/runs/{id}/reflect`；`GET /api/negative-motifs` 返回经验。可从未通过完整任务校验但已有局部修复的轨迹学习。

财务沙箱工作台有“启用已验证负 motif”独立开关，默认关闭；ReAct 和 Graph 都可使用。请求字段为 `negativeMotifs: true`。每次执行冻结经验选择，并核对场景、实例和工具契约。开启时注入固定的字段绑定提示；工具前检查必须同时具备当前 list_payments 观察及当前状态证据。

命中错误绑定时，不执行写工具，返回当前合法候选回款 ID，让模型决策。不会静默替换参数、复用历史 ID 或禁用整个工具。尝试仍计入 toolCalls 和 toolErrors，同时单列 negativeMotif.guardHits；因此不能将“拦截发生”宣称为已减少模型调用。真正的节省需要提示使模型不再生成错误，或者后续经过验证的自动修复机制。

已有进化实验会在训练、候选验证结束后提取局部负经验，连同拒绝晋升证据保留在该实验的 negative-motifs 子目录。它们不在同轮验证过程中启用、不污染公共经验库；当前仍没有把负 motif 自动合成下一代完整图，需独立验证组合版本。保持这一边界避免训练/验证泄漏。

## 验证

自动测试覆盖：整任务失败可提取局部经验但不能晋升正图；无修复、错误来源、重放不一致拒绝编译；新 ID 重绑定；正确调用不被拦截；缺少当前观察、旧契约不命中；错误计量保持完整；原运行保持不变。

从真实负向实验运行 `3da03450-743f-4bc6-84dc-ff9086258632` 的失败事件 47、修复事件 50 提取负 motif `dcf6ccb0-c6b6-4c88-b4e7-e537bea3aa55`，包含上游 list_payments 观察。隔离重放 17 次工具调用，额外 LLM 0。此证据验证局部字段绑定修复，不证明先前整项成本退步由该错误引起。串行上下文导致后续串行调用仍待消融验证。

真实模型链路验证 `d7a931de-fa59-4568-a08e-373d30beec00`：qwen/qwen3.5-27b、关闭 thinking、批量工具调用、Graph + 负 motif、changed 财务完整任务。6 次 LLM、21 次工具、0 工具错误、输入 35,446 / 输出 2,502 token、35.649 秒，完整状态校验通过。负经验已加载，模型直接生成合法 ID，guardHits=0。该运行不是与旧失败样本的受控 A/B，不能据此宣称平均收益或错误消除率；前置拦截路径由注入调用测试验证，不能把注入测试当作真实模型结果。

报告语义仍未通过人工事实核对：将实际分配合计 5,490,000 分写成 5,790,000 分，最终答复覆盖发票数量也有误。此类聚合数值错误尚不属于本次字段绑定负 motif，不能把 0 工具错误解释为输出完全正确。
