双方均通过的 29 对单独列示：Plan + ReAct 539,072 token，RSI 455,698 token，减少 15.5%；平均延迟分别 32.73 s、31.12 s，减少约 4.9%。该子集不能代替上述包含失败的总成本统计。

只有三个任务命中已有图，其余 27 个 RSI 任务仍调用 Plan。本轮证明基线采用 Plan 后仍可观察到结构化图执行的系统收益，但不是固定同一份 Plan 的纯执行器消融，也不能独立证明 Plan 缓存、递归进化或长期可靠性收益。RSI 工具调用和工具错误反而更多，后续需要继续优化按需读取与模型报告步骤。

报告文字质量与该性能评测分开，用 LLM-as-Judge 的 0–10 维度分数和 0–1 reward 评价。裁判调用不混入上述 Agent 成本，不能仅根据结构化通过声称报告质量完全相同。裁判配置和协议见 [llm-judge.md](llm-judge.md)。
